# SPA htmx untuk Sistem Peminjaman Kunci Lab — Implementation Plan

> **For agentic workers:** Choose one: superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mengubah sistem server-rendered Django menjadi SPA htmx ringan sehingga navigasi, paginasi, pencarian, dan submit form tidak melakukan reload halaman penuh.

**Architecture:** Template tetap extend `base.html`. Konten dibungkus dalam `<div id="main-content">`. Seluruh tautan/filter/pagination/form diberi atribut htmx (`hx-get`/`hx-post` + `hx-target="#main-content"` + `hx-select="#main-content"` + `hx-push-url`). Views, forms, urls, models TIDAK diubah SAMA SEKALI. htmx mengekstrak fragmen `#main-content` dari respons HTML penuh (termasuk setelah redirect) dan menukarnya in-place.

**Tech Stack:** Django 6, htmx 1.9.12 (CDN), Bootstrap 5.3, jQuery 3.7 (tetap untuk form AJAX peminjaman).

## Global Constraints

- Jangan mengubah file di `apps/**/views.py`, `forms.py`, `urls.py`, `models.py`, atau `config/urls.py`.
- htmx diambil dari CDN `https://unpkg.com/htmx.org@1.9.12/dist/htmx.min.js`.
- Container konten bersifat GLOBAL: `<div id="main-content">` di `base.html`; semua `hx-target` dan `hx-select` merujuk `#main-content`.
- Semua tautan navigasi memakai pola tautan (lihat bawah): `hx-get="<url>" hx-target="#main-content" hx-select="#main-content" hx-push-url="true"`.
- Form GET (pencarian/filter) memakai pola: `hx-get="<list_url>" hx-target="#main-content" hx-select="#main-content" hx-push-url="true"` pada tag `<form>`.
- Form POST (create/update/delete/pengembalian) memakai pola: `hx-post="<url>" hx-target="#main-content" hx-select="#main-content"` pada tag `<form>`. Token CSRF tetap dirender `{% csrf_token %}` (dibacakan htmx dari form) sehingga lulus validasi Django.
- Link export Excel/CSV di laporan TIDAK di-swipe; diberi `hx-boost="false"` (atau dibiarkan tanpa atribut hx) agar browser mengunduh file normal, bukan menampilkan HTML.
- Simbol nama URL (dari `reverse`) sudah ada di template; pertahankan nama URL yang sama.
- Bahasa UI tetap Indonesia; jangan ubah copy/teks yang ada.
- `static/js/main.js` (auto-close alert) TIDAK diubah.
- Komit per tugas dengan pesan singkat (contoh: `refactor: buat navigasi SPA htmx di base.html`).

- [ ] **Step 5: Form (`mahasiswa_form.html`)**

Ubah form (baris 13):
```html
<form method="post" hx-post="{% url 'mahasiswa_create' %}" hx-target="#main-content" hx-select="#main-content">
```
> Catatan: `mahasiswa_form.html` dipakai untuk create DAN update (CreateView/UpdateView). URL `hx-post` harus bernilai URL aktif saat halaman dirender.
```html
<form method="post" hx-post="" hx-target="#main-content" hx-select="#main-content">
```
Tautan Batal (`{% url 'mahasiswa_list' %}` baris 25) jadikan pola tautan navigasi.
